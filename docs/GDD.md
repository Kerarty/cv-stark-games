# GDD: «Испытание кандидата» — интерактивное резюме для Stark Games

Одностраничное статическое веб-приложение без сборки и зависимостей. Открывается с телефона, играется пальцем.

## Рамка

Рекрутер — «вербовщик гильдии», кандидат проходит испытание из трёх миров, по одному на игру студии. Прогресс «0/3» в HUD растёт при посещении миров. Всё честно проходится за 3–5 минут, каждая секция читается и без игры.

## Экраны

### 0. HUD (fixed)
Имя и роль · прогресс «Испытание N/3» · тумблер «Режим дизайнера» · RU/EN · кнопка PDF.

### 1. Хаб
Герой: имя, роль, три факта (БГУИР, системный дизайн и баланс, 7+ прототипов). Три карточки миров с кнопками-переходами. Кнопка «Просто резюме (PDF)» — для тех, кто не играет.

### 2. Мир 1 «Грани Реальности» — лист персонажа
Тема: тёмное фэнтези, пергамент и золото. Класс и уровень (курс БГУИР). Шесть статов с анимированными полосами; в режиме дизайнера под статом показывается обоснование. Три квеста-карточки (раскрываются): варгейм, GDD стратегии, echoloop — у каждого «награда» = навык, переведённый на язык студии (live ops, документ для команды, прототип). Три достижения-бейджа.

### 3. Мир 2 «Tile Seasons» — сундук инструментов
Тема: сочный пастельный match-3. Сетка 6×5, шесть типов тайлов. Свайп/клик двух соседних тайлов — обмен; матч 3+ сгорает, каскады считаются. Каждый успешный матч открывает следующую карточку инструмента (всего 6). Лимита ходов нет — прогресс гарантирован (дизайн-правило: резюме не должно быть сложнее работы). Открытые карточки остаются в «сундуке» ниже сетки.

### 4. Мир 3 «Ёлочка» — финал
Тема: уютная зима. Ёлка из CSS-слоёв, на ней шары-контакты: телефон, email, GitHub, PDF, открытка. Открытка кликом раскрывает текст «Почему Stark Games». Финальная кнопка «Отправить резюме в гильдию» → mailto:hr@stark.games. После посещения всех трёх миров на ёлку «зажигается» звезда.

## Режим дизайнера

Тумблер в HUD. Включён: под каждым блоком появляется плашка «почему так» с обоснованием решения. Это демонстрация дизайн-мышления — резюме объясняет собственные механики.

## Технические решения

- Файлы: `index.html` (каркас) · `styles.css` · `content.js` (весь текст RU/EN) · `games.js` (match-3) · `main.js` (язык, рендер, прогресс).
- Ноль внешних зависимостей: системные шрифты, эмодзи-тайлы, CSS-графика. Страница открывается мгновенно.
- Доступность: контраст ≥ 4.5:1, цели ≥ 44×44, focus-visible, prefers-reduced-motion, семантика и aria.
- Печать: @media print — HUD и игры скрыты, все блоки раскрыты, чистое резюме.
- Язык и режим дизайнера сохраняются в localStorage.

## Метрики успеха

1. Суть резюме видна за 3 секунды без скролла.
2. Полное прохождение ≤ 5 минут.
3. Работает с телефона без установки и лагов.
4. В режиме дизайнера читается аргументация каждого решения.
